Weekly routine (about 2 hours)
  1. Send 5–10 messages: 2 featured places, 1–2 colleges, 1 city news desk (more before Holi / Ganga Mela, Navaratri–Durga Puja, Dev Deepawali).
  2. Set up 1–2 profiles until the list is done (Google Business Profile first).
  3. Answer 2–3 genuine Reddit/Quora questions; link only when our guide answers it.
  4. Publish a story and cross-post it from admin → Syndication.
  5. Monthly: check Moz Link Explorer and Search Console → Links; note new linking sites in the sheet.
