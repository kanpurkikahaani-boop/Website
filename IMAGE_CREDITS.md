# Image credits & shopping list

The site currently renders a warm gradient tile (with the place name) wherever a photo is missing, so it looks finished without any images. Add real photos at the paths below and they appear automatically on the next `npm run dev` / `npm run build` (the `scan-assets` script detects them).

## Rules

1. **Every photo must actually show the place it is labelled as.** Do not reuse a generic temple or another city's ghat.
2. Use free-licence sources and keep attribution: Wikimedia Commons (check the licence on each file page — CC BY / CC BY-SA need credit), Unsplash and Pexels (free, credit appreciated).
3. Save as **JPG**, landscape, at least **1600 px wide** (hero images 2400 px), ideally under 400 KB. `next/image` handles resizing and AVIF/WebP.
4. Record each image in the table: fill in *Source URL*, *Author* and *Licence*.

**117 images** are referenced in `src/data/`. Some are shared between pages (e.g. a place card and a news story).
